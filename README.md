# С днём рождения, Лизка!

Интерактивная 3D-открытка ко дню рождения: праздничная 3D-сцена, торт со свечами, письмо, музыка и анимации.

## Локальный запуск

```bash
pnpm install
pnpm dev
```

## Сборка

```bash
pnpm build
```

Проект подготовлен для публикации в Cloudflare. Основная ветка — `main`.
